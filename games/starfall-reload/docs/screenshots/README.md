# Screenshots

Native 640×360 frames copied from the WebGPU canvas of the development build in a Chromium-based browser, 23 November 2026. The frames show real gameplay flown by the demo autopilot, started with the development-only `?area=…&at=…&power=…&weapon=…` parameters to reach each boss. Boss frames were picked from the densest bullet patterns of each fight. The CRT overlay is a CSS layer and is not part of the canvas pixels.
